# 🍕 Pizza Sales Analytics

An end-to-end Data Analytics and Business Intelligence project using **SQL Server, T-SQL, Power Query, Power BI and DAX** to analyze pizza sales performance and generate business insights.

## 📌 Project Overview

This project analyzes pizza sales data to understand:

* Revenue performance
* Order volume
* Pizza sales
* Average Order Value
* Monthly trends
* Top and bottom-performing pizzas
* Category and size performance
* Revenue contribution
* MoM and YoY performance

## 🛠️ Tech Stack

* **SQL Server** — Data storage and SQL analysis
* **T-SQL** — Data validation and business analysis
* **Power Query** — Data transformation
* **Power BI** — Dashboard and visualization
* **DAX** — Business calculations and analytical measures
* **GitHub** — Version control and project documentation
